Notice

Most files on this site have been converted from their original file format of Microsoft Powerpoint to Adobe's PDF if their size was larger than 5 MB. Most video files have been converted to standard MPEG-1 format for easier compatibility and reduced file size. Due to these changes, most video files will not run in the presentation, but will work as a stand alone file. In a few cases, the original video files were included, with the MPEG-1 files being an optional download.

The original presentations and videos are being distributed on DVD through the CAA. Please contact Graham Greene by phone at 44-1-293-573-462 for more information.

Viewers

The files contained on this site are in either Microsoft PowerPoint (.ppt) or Adobe Portable Document Format (.pdf). Presentations that included videos have been compressed using Winzip (.zip) technology. Please visit the sites below to download the latest viewers.


Windows XP users do not require Winzip.

Web Browsers

It is recommended that you have the latest web browsers available to view this site. In addition, javascript and style sheets should be enabled; these are normally enabled by default.
